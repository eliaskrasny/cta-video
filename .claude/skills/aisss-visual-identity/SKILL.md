# AISSS visual identity

Source of truth: `branding/AISSS-Visual-Identity.pdf` (14 pages, October 2026). This skill is that guide in agent form. Page numbers in brackets, like [p.6], point to the PDF page. If the skill and the PDF ever disagree, the PDF wins; tell the user so the skill can be fixed.

The PDF is built from `branding/guide/build_guide.py`. Colours here come from the same table (`tokens.json`, generated by `branding/guide/export_skill_tokens.py`), so they cannot drift.

## The idea [p.3]

The company explains ideas and does not lobby. The design follows the writing: plain, short, readable.

1. **Plain first.** Ink on Paper. Square corners. No shadow, no gradient. Inter stays roman; italic belongs to Baskerville, only in a quote.
2. **One colour.** Strand does one job in a frame: a word, a short rule, or a state. A second Strand item means the first one goes.
3. **Readable.** Sentence-case headlines. Inter small caps for labels. Body text large enough to brief from, left aligned.

Audiences: policymakers, educators, journalists, the public. Where researchers disagree, the piece says so.

## Non-negotiables

**Logo** [p.4–5]
- Use the SVG files. Never redraw the yarn. Lockup is horizontal only: `AISSS-logo-black.svg` / `AISSS-logo-white.svg`. No stacked version. Mark alone (`yarn-mark-*.svg`) only when the name is already on screen.
- Mark and wordmark are one colour: Ink `#111111` or Paper `#FFFFFF`. Never Strand.
- Clear space = the height of the yarn mark on every side. Minimum lockup 128px / 32mm wide; minimum mark 28px / 8mm.
- Put it on a solid Ink, Paper or warm-paper field, never on a photo or pattern. Don't stretch, rotate, flip, crop, shadow, outline or glow it.
- The letters are `AISSS`. In a sentence write "AI Safety Said Simply".

**Colour** [p.6–9]
- Ink and Paper fill most of a frame. Strand is the short share: one word, one 1.5–2pt rule, or one mark. Not body text, not a background.
- Warm Paper `#F4EFE6` is for video and long documents. One ground per frame: never Warm Paper and Paper together.
- Signals (Indigo, Moss, Saffron) are for diagrams only: one signal per figure, plus Ink. Never in a headline, never on a line with Strand.
- Do not set Live, Ember, Wheat or Saffron as text on Paper. Do not run body copy on Strand, Live or Saffron.
- Don't add pure black next to Ink.

**Type** [p.10–11]
- Inter for body, buttons, navigation, the wordmark and small-cap labels. Baskerville Bold for heading 1 and 2, Baskerville Regular for heading 3 and captions, Baskerville Italic for quotes only. Redaction 35 Regular for the website hero's first clause only.
- Sentence case. Left aligned. Never justify, never centre a paragraph. Body lines about 60–75 characters.
- Bold Inter is the wordmark and small caps, not a paragraph.

**Shape and graphics** [p.3, p.12]
- Square corners, flat colour. No shadows, glows, outlines, gradients.
- At most one strand loop per layout; stroke is Ink, Paper or Strand; scale evenly; ends leave the frame. A Strand loop means the headline is not Strand.
- A Strand underline is a straight rule, 1.5–2pt, about the length of the word. It is not a loop.

When something isn't covered: **the quieter choice** [p.2].

## Palette at a glance [p.6–8, p.14]

| Name | Hex | Role |
|---|---|---|
| **Ink** | `#111111` | Text, logo, dark fields, primary buttons |
| **Paper** | `#FFFFFF` | Default ground; type and logo on Ink |
| **Strand** | `#C64D0A` | One word or one short rule. Not body text |
| Ink 2 / Muted | `#262626` / `#595959` | Secondary headlines / captions and metadata |
| Line 2 / Line | `#858585` / `#D4D4D4` | Disabled and quiet icons (never sentences) / hairlines |
| Paper 3 / Paper 2 | `#EBEBEB` / `#F5F5F5` | Inactive cards / bands and secondary buttons |
| Warm Paper | `#F4EFE6` | Video and long-document ground |
| Wool / Wheat | `#E3D5C3` / `#CDBBA4` | Panels and lower thirds / second panel or chart band (not text) |
| Bark | `#5C534C` | Captions and axes on warm grounds |
| Clay | `#8C3410` | Small orange labels and icons |
| Live | `#FF8A3D` | Large "available" fills, Ink type on top |
| Ember | `#F57828` | Live hover only |
| Indigo / Moss / Saffron | `#1B3A4B` / `#1E5C44` / `#E2A100` | Diagram structure / confirmed point / a tick or short underline |

Core (Ink, Paper, Strand, neutrals) is what the website uses. Everything else is for video, diagrams and print.

## Type at a glance [p.10–11]

| Role | Face | Notes |
|---|---|---|
| Accent label | Inter Bold, small caps | tracked, e.g. `reward hacking`. Never Baskerville |
| Heading 1 / 2 | Baskerville Bold | sentence case; H2 smaller |
| Heading 3 / caption | Baskerville Regular | |
| Body | Inter Regular 400 | left aligned |
| Buttons | Inter Medium 500 | |
| Navigation | Inter Semibold 600, 12px | small caps |
| Wordmark (web) | Inter Bold 700, 29px, −0.055em, 3px from a 36px mark | video and print use the SVG |
| Quote | Baskerville Italic | the only italic |
| Website hero | Redaction 35 Regular, then Inter Medium in Strand, then an Ink period | one clause only |

Files: `branding/guide/fonts/` (Inter static weights, Libre Baskerville as the Baskerville stand-in, Redaction). Inter is open source (SIL OFL), so it is safe to bundle. Never rely on system fonts.

## Before delivering

- [ ] One Strand moment per frame (or one loop, or neither).
- [ ] Logo is the SVG, unedited, one colour, on a solid field, with clear space.
- [ ] Square corners; flat colour; no shadow, gradient, glow or outline.
- [ ] Headlines are Baskerville Bold in sentence case; body and labels are Inter; only quotes are italic.
- [ ] Every text/background pair is on the approved list in [reference/colour.md](reference/colour.md) (or `scripts/contrast.py` says AA or better for body text). Fix failures; don't note them.
- [ ] No Warm Paper next to Paper; no signal colour in a headline or beside Strand.
- [ ] Left aligned, ~60–75 characters a line for body copy.
- [ ] Animation? Then also run the checklist in `paper-cutout-animation/SKILL.md`.
