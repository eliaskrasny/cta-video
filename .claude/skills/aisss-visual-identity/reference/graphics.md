# Graphics: Strand loops [PDF p.12, p.14]

One open stroke, with round ends, then off the edge. **One loop in a layout.** Scale it evenly, stroke included.

| File | Role |
|---|---|
| `strand-drift.svg` | A single loop, horizontal |
| `strand-double.svg` | Two loops, still one element |
| `strand-corner.svg` | Enters from the top, leaves at the bottom. Covers and end cards |

Location: `branding/guide/graphics/`. Stroke uses `currentColor`: set Ink, Paper or Strand.

## Use [p.12]
- One loop in a layout. The double loop counts as the one.
- Scale it evenly. Do not thicken the stroke to match a headline.
- Ink on a light ground. Paper on Ink. Strand on Warm Paper is also shown in the guide.
- **A Strand loop means the headline is not Strand.** One Strand job per frame.
- The ends run off the edge, or behind a solid panel.

## Do not [p.12]
- Trace the logo, or tile the loops into a pattern or a border.
- Stretch the path to fill a banner. No shadow, gradient or second stroke.
- Use a loop as a bullet.
- End the line in the middle of a sentence.

## Underline [p.12]
A Strand underline is a **straight rule, 1.5 to 2pt, about as long as the word**. It is not a loop. (In the paper-collage animation style the hand-drawn pen underline is the one deliberate exception: see `paper-cutout-animation`.)
