# Logo [PDF p.4–5, p.14]

The yarn is the mark. AISSS sits beside it. **This pair is the only lockup. There is no stacked version.**

## Files

| File | Use |
|---|---|
| `AISSS-logo-black.svg` | Primary lockup, Ink on Paper, Paper 2, Paper 3 and Warm Paper |
| `AISSS-logo-white.svg` | Primary lockup, Paper on Ink |
| `yarn-mark-black.svg` | Mark alone on light grounds, when the name is already on screen |
| `yarn-mark-white.svg` | Mark alone on Ink |

Location: `motion/public/brand/` (used by the animation system) and `branding/guide/logos/` (used by the PDF build). Favicons and PNGs are in the zips under `branding/`. In Remotion's flat system use `<LogoLockup>` / `<YarnMark>`; never place the files yourself.

## Rules

- Use the SVG. Leave the yarn drawing alone. The wordmark in the SVG is outlined, so it needs no installed font.
- Mark and wordmark share one colour: **Ink or Paper**. Strand does not recolour the logo.
- On a photograph, put the lockup on a solid Ink or Paper field.
- Mark alone only when the name is already on screen.

### Clear space [p.4]
Leave a margin **the height of the yarn mark** on every side. The gap inside the lockup is part of the file. On the web the gap is 3px next to a 36px mark. Type, loops and other marks stay outside the clear-space box.

### Minimum size [p.4]
| | Print | Screen |
|---|---|---|
| Lockup | 32mm wide | 128px wide |
| Mark alone | 8mm | 28px |

### Wordmark [p.4]
The letters are `AISSS`. In a sentence, write **AI Safety Said Simply**. The accessible name on the lockup is the full name ("AI Safety Said Simply"), the visible wordmark is `AISSS`.

### Colour combinations [p.5]
| Combination | OK |
|---|---|
| Ink on Paper | yes |
| Paper on Ink | yes |
| Ink on Warm Paper | yes |

## Do not [p.5]
1. Stretch or condense the lockup.
2. Set the wordmark in Strand, or split the colours.
3. Rotate, flip, or crop the yarn.
4. Add a shadow, an outline, or a glow.
5. Let type enter the clear space.
6. Sit it on a photo or a pattern.

In video: fade or cut the logo in; don't animate it otherwise, and never put it on a moving image without a solid field.
