# Stock images

Licensed stock photos only. They're shown in greyscale on a paper mount (`<PhotoCutout>`), so colour doesn't matter.

**Name:** `<subject>-<site>-<id>.jpg`, lower case with hyphens, e.g. `data-centre-unsplash-x7k2.jpg`, `capitol-pexels-30412.jpg`.

**Add a row to `credits.csv`:**

| Column | Example |
|---|---|
| file | data-centre-unsplash-x7k2.jpg |
| source | Unsplash |
| creator | Jane Doe |
| url | https://unsplash.com/photos/x7k2 |
| licence | Unsplash License |
| added_by | your initials |

**Allowed:** photos whose licence allows use in a YouTube video (Unsplash, Pexels, or a paid licence the team holds). Real places, objects and everyday scenes.

**Not allowed:**
- AI-generated images, illustrations, 3D renders, clip-art.
- Clichés: robots, glowing brains, blue circuit boards, red-eyed machines, hooded hackers.
- Stock photos standing in for a real person in the story. Use their real photo (in `real/`) or none.
- Anything with a visible watermark.
