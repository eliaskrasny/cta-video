# Source photos for cut-outs

Transparent PNGs of the objects that become paper cut-outs. They are small, so they are committed.

| File | Used as |
|---|---|
| `microscope.png`, `gavel.png`, `clipboard.png`, `microphone.png`, `megaphone.png` | cut-outs in `C01-org-chart` |
| `pin.png` | the pin (also copied to `public/collage/pin.png`) |
| `money.png` | spare, not used yet |

To use a photo: add it to `tools/collage/cutouts.json`, then run `bake_cutout.py` (commands in `src/collage/README.md`). It writes the finished sticker to `public/collage/cutouts/`.
Keep originals bigger than about 2400 px on the long edge out of git.
